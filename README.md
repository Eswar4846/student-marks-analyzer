## Description

Student Marks Analyzer is a beginner Python project that uses NumPy
to analyze student marks.

The program accepts student names and marks, calculates totals and
averages, determines pass/fail status, ranks students, and exports
results to a CSV file.

## Features

- Accepts multiple students
- Accepts marks for three subjects
- Validates marks between 0 and 100
- Calculates total marks
- Calculates student averages
- Calculates subject-wise averages
- Determines pass/fail status
- Finds the best student
- Ranks students
- Exports results to CSV
